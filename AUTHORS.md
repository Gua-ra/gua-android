Gua for Android is maintained by the Gua project. It is a fork of [Element X Android](https://github.com/element-hq/element-x-android). This repository's history includes upstream's, so its [contributor graph](https://github.com/Gua-ra/gua-android/graphs/contributors) lists Element's contributors along with Gua's.

Gua ships the code and translations written by Element X Android's [contributors](https://github.com/element-hq/element-x-android/graphs/contributors) and translators.
